# External services & operational readiness matrix — 2026-11-14

**Method:** every row is classified as exactly one of:

- **TESTED** — implemented and verified in this repository (local or hosted,
  evidence cited)
- **IMPLEMENTED-NOT-ACTIVATED** — code exists, no provider/account/credential,
  nothing is switched on; fail-closed by construction
- **INCOMPLETE** — part exists, part does not; gaps stated
- **OWNER-ACTION** — requires an account, purchase, credential, approval or
  physical presence the agent cannot supply; prepared but not executed

**No provider is activated in this batch. No credentials were used. No real
customer data, payment, invoice or tax submission exists anywhere in this
evidence.** Staging acceptance (run 43709710950) is hosted evidence for the
browser flows only; it does not certify anything in this table.
